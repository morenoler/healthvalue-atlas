# Проверка проекта

Дата локальной проверки: 4 октября 2026 года. Среда: Windows, Python 3.13.12. Основные версии библиотек зафиксированы в requirements.txt.

## Данные и расчёты

Полная сборка завершилась на реальных исходных данных. Контрольные суммы 11 файлов совпали с манифестом. Результат: 46 стран, 644 строки сетки и 614 наблюдений с исходом. Итоговые таблицы, графики и JSON приложения созданы из одного расчёта.

Временной эксперимент использует 403 строки обучения, 84 строки калибровки и 76 строк теста. Random Forest с минимальным листом 10 выбран по валидации. Вариант с листом 4 имеет немного меньшую ошибку на тесте, но выбор не меняется. Это сохраняет независимость тестовой оценки.

## Автоматические проверки

14 тестов прошли локально. Они проверяют:

- контрольные суммы источников и ключи таблицы;
- пропуски исхода и диапазоны долей;
- отсутствие лага через пропуск календарного года и между странами;
- обучение преобразований только на тренировочной выборке;
- независимость валидационных прогнозов и выбора модели от будущего исхода;
- формулу квантили калибровки;
- соответствие данных приложения и расчётных метрик;
- API, фильтры, диапазон сценария и порядок границ интервала.

## Интерфейс

Проверены четыре раздела приложения. В браузере выполнены следующие действия:

- смена страны на США, смена года на 2019 и выбор профилактики;
- выбор страны на графике мышью и клавиатурой;
- просмотр страны без исхода за выбранный год: Норвегия, 2023;
- сценарий снижения расходов на 20% с корректным порядком границ;
- просмотр метрик моделей и прогнозов по выбранной стране;
- поиск `pol` и поиск без совпадений;
- мобильный режим около 390 CSS-пикселей: горизонтального переполнения страницы нет;
- проверка консоли: ошибок JavaScript нет.

Скриншот основной страницы находится в reports/figures/dashboard.jpg. Вёрстка использует локальные CSS и JavaScript. Отображение данных не зависит от CDN.

## Воспроизведение

```bash
python -m healthvalue build
python -m pytest -q
```

GitHub Actions повторяет сборку и тесты на Linux. Актуальный статус доступен во вкладке Actions репозитория.
