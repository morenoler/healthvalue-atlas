# Методология

## Вопросы

1. Как расходы и смертность связаны между странами в одном году?
2. Сохраняется ли связь при учёте постоянных различий между странами и общих годовых сдвигов?
3. Помогают ли экономические и демографические признаки предсказать смертность на следующий год?

Основной исход: возрастной стандартизованный показатель смертности от причин, при которых помогает своевременное лечение. Каждая страна имеет одинаковый вес. Страны и годы с пропусками исхода не входят в оценку.

## Описательный анализ

Срез использует один общий год. В нём рассчитываются медианы, ранговая корреляция Спирмена и положение страны. Для изменения за 2010-2023 годы используются только страны с обоими наблюдениями. Это защищает сравнение от смены состава выборки между двумя датами.

Приложение выбирает пять аналогов по евклидову расстоянию между двумя признаками: логарифм реального ВВП на человека и доля населения 65+. Масштаб каждого признака задаёт его стандартное отклонение в выбранном году среди стран с доступным исходом. Смертность не участвует в расчёте расстояния.

## Панельная модель

```text
log(mortality[i,t]) = country_effect[i] + year_effect[t]
                   + beta * log(spending_proxy[i,t-1])
                   + gamma * log(real_gdp[i,t-1])
                   + delta * age65[i,t-1]
                   + theta * out_of_pocket_share[i,t-1] + error[i,t]
```

Метод оценки: OLS с индикаторами стран и лет. Стандартные ошибки кластеризованы по странам. Для интервалов используется t-распределение и поправка на размер выборки. Полнота ранга матрицы проверяется до расчёта.

Для сценария роста расходов на `p%` относительное изменение равно `100 × ((1 + p/100)^beta - 1)`. Границы доверительного интервала проходят через ту же формулу. При отрицательном `p` порядок границ меняется. Сценарий ограничен диапазоном -20% - +20%.

Сценарий использует общий коэффициент. Выбор страны меняет только исходную величину, к которой применяется процент. Модель не даёт индивидуальную оценку эффекта для каждой страны. Для изменения расходов в году `t` формула соответствует связи с исходом следующего года. Показатель выбранного года в приложении служит условной точкой отсчёта.

Пять спецификаций:

1. Контрольные признаки и эффекты лет без эффектов стран.
2. Основная модель с эффектами стран и лет.
3. Основная модель на периоде до 2020 года.
4. Основная модель для текущей группы высокого дохода.
5. Основная модель с отдельными линейными трендами стран. Один тренд служит опорой, чтобы избежать линейной зависимости с эффектами лет.

Высокий R² модели с эффектами стран не доказывает точность будущего прогноза. В этой задаче он во многом отражает постоянные различия стран. Для прогноза служит отдельный временной эксперимент.

## ML и временная проверка

Цель модели: изменение смертности относительно прошлого года. Итоговый прогноз равен прошлому значению плюс прогноз изменения. Отрицательный итог обрезается до нуля.

Признаки: прошлогодние значения обеих категорий смертности, логарифмы расходов и ВВП, доли людей 65+, прямых платежей, государственного финансирования и городского населения. Дополнительные признаки: ISO3 и год прогноза. Идентификатор страны кодируется One-Hot. Медиана и StandardScaler обучаются внутри каждого обучающего набора.

Кандидаты: прогноз по прошлому году, Ridge с alpha 1, 10 и 100, Random Forest с минимальным листом 4 и 10. В каждом лесу 200 деревьев. Доля признаков 0,8. Seed равен 42.

- Валидация: четыре expanding-window шага. Тестовый год каждого шага: 2016, 2017, 2018 и 2019. Обучение использует только более ранние годы.
- Выбор: минимальная MAE по всем наблюдениям этих четырёх шагов.
- Финальное обучение: доступные наблюдения до 2019 года включительно.
- Калибровка: 2020-2021 годы. Эти строки не участвуют в подборе параметров и финальном обучении.
- Тест: 2022-2023 годы. Метрики всех кандидатов публикуются, но выбор после теста не меняется.

Тест проверяет перенос модели на будущие годы для известных стран. Он не проверяет перенос на новую страну. Лаг за 2022 год в прогнозе на 2023 год допустим для последовательного прогноза на один год. Многолетний прогноз без новых фактов потребовал бы другого эксперимента.

Данные представляют одну текущую версию истории. Здесь нет архивов публикаций по датам. Реальные задержки отчётности не моделируются. Это ограничивает применение метрик к прогнозу в реальном времени.

Важность признаков рассчитана отдельно на валидации 2019 года. Модель для этой проверки обучается только до 2018 года. Каждый признак перемешивается 20 раз. Изменение MAE показывает вклад признака в прогноз этой модели. Оно не измеряет причинный эффект. Корреляция признаков может снижать их отдельную важность. Ошибки на тесте также доступны по странам и годам.

## Интервалы и неопределённость

Ширина интервала прогноза равна квантилю абсолютных ошибок на калибровочном периоде. Ранг квантили: `ceil((n+1) × 0.9)`, не выше `n`. Нижняя граница не может быть меньше нуля.

Это split-conformal-подобная калибровка по времени. Страновые наблюдения зависимы, а пандемия меняет распределение ошибок. Поэтому теоретическая гарантия 90% покрытия здесь не заявляется. Вместе с номинальным уровнем публикуются фактическое покрытие на тесте и ширина интервала. Широкий интервал может давать высокое покрытие и слабую практическую точность.

Разница MAE с базой проверяется бутстрэпом по странам: 2 000 повторов, seed 42. Все годы одной страны остаются в одном блоке. Общие шоки между странами остаются ограничением.

## Ограничения

Агрегированные данные не описывают исход отдельного пациента. Расходы и здоровье могут влиять друг на друга. В модели нет полного набора факторов риска, устройства системы и качества кодирования смертей. Эффекты стран и лет не решают эти проблемы полностью. Для вывода о реформе нужен отдельный причинный дизайн.
