# Данные и источники

## Охват

Исследование использует 46 стран из выгрузки ОЭСР. Основной период: 2010-2023 годы. Экономические признаки за 2009 год нужны для лага в первой строке. Итоговая сетка содержит 644 пары «страна - год». Показатель смертности есть в 614 парах. В срезе за 2023 год расходы и смертность есть у 36 стран.

Мы фиксируем 2023 год как конец исследования. Это даёт общий период для источников и отдельные годы для теста. Дата загрузки данных не означает, что все показатели доступны за этот год.

## ОЭСР: смертность

- Источник: [OECD Health Statistics](https://www.oecd.org/en/data/datasets/oecd-health-statistics.html).
- Набор: `OECD.ELS.HD,DSD_HEALTH_STAT@DF_AM,1.1`.
- [Определения показателей](https://www.oecd.org/en/publications/health-at-a-glance-2025_8f9e3f98-en/full-report/avoidable-mortality-preventable-and-treatable_e2e21c0b.html).
- [Методика возрастной стандартизации](https://stats.oecd.org/wbos/fileview2.aspx?IDFile=41dfcc30-110a-4b7a-ac94-d6b8874e27cd).

Фильтры: `SEX=_T`, `AGE=_T`, `UNIT_MEASURE=DT_10P5HB`, `CALC_METHODOLOGY=STANDARD`. `_T` в поле возраста не означает отсутствие порога: определение самих показателей задаёт возраст до 75 лет. Стандартизация использует население ОЭСР 2015 года.

- `TRTM` → `treatable`: смерти от причин, при которых своевременное и эффективное лечение может предотвратить смерть.
- `PREVM` → `preventable`: смерти от причин, на которые могут повлиять профилактика и меры общественного здоровья.
- `AVM` → `avoidable`: сумма двух категорий.

Единица: число смертей на 100 000 после возрастной стандартизации. Это показатель для сравнения стран. Его нельзя умножить на фактическое население и получить точное число смертей.

## ВОЗ: расходы на здравоохранение

Первичный источник финансовых показателей: [WHO Global Health Expenditure Database](https://apps.who.int/nha/database/). Проект получает эти ряды через World Bank WDI, источник API `2`. Это одна цепочка происхождения данных. ВОЗ и Всемирный банк здесь не служат независимыми измерениями одного показателя.

- [`SH.XPD.CHEX.PP.CD`](https://data.worldbank.org/indicator/SH.XPD.CHEX.PP.CD) → `spend_ppp`: текущие расходы на человека, международные доллары по ППС, текущие цены.
- [`SH.XPD.CHEX.GD.ZS`](https://data.worldbank.org/indicator/SH.XPD.CHEX.GD.ZS) → `health_gdp_pct`: текущие расходы как доля ВВП, %.
- [`SH.XPD.GHED.CH.ZS`](https://data.worldbank.org/indicator/SH.XPD.GHED.CH.ZS) → `public_share`: внутренние государственные расходы как доля текущих расходов, %.
- [`SH.XPD.OOPC.CH.ZS`](https://data.worldbank.org/indicator/SH.XPD.OOPC.CH.ZS) → `oop_share`: прямые платежи домохозяйств как доля текущих расходов, %.

## Всемирный банк: контекст

[Документация API](https://datahelpdesk.worldbank.org/knowledgebase/articles/889392).

- [`NY.GDP.PCAP.PP.KD`](https://data.worldbank.org/indicator/NY.GDP.PCAP.PP.KD) → `gdp_ppp_constant`: реальный ВВП на человека по ППС, международные доллары 2021 года.
- [`SP.POP.65UP.TO.ZS`](https://data.worldbank.org/indicator/SP.POP.65UP.TO.ZS) → `age65_pct`: доля населения 65+, %.
- [`SP.DYN.LE00.IN`](https://data.worldbank.org/indicator/SP.DYN.LE00.IN) → `life_expectancy`: ожидаемая продолжительность жизни при рождении, лет.
- [`SP.POP.TOTL`](https://data.worldbank.org/indicator/SP.POP.TOTL) → `population`: население, человек.
- [`SP.URB.TOTL.IN.ZS`](https://data.worldbank.org/indicator/SP.URB.TOTL.IN.ZS) → `urban_pct`: доля городского населения, %.

Названия стран, регионы и группы дохода приходят из справочника стран WDI. Группа дохода отражает классификацию на дату выгрузки. Для исторической классификации нужен другой источник.

## Преобразования

`spend_real_proxy = health_gdp_pct / 100 × gdp_ppp_constant`.

Это приближение расходов в постоянных ценах через общий дефлятор экономики. Оно не равно ряду с отдельным индексом цен медицинских услуг. Прокси нужен для временной модели. Текущие доллары по ППС нужны для сравнения стран в одном году.

Соединение таблиц проходит по ISO3 и году. Каждая пара должна быть уникальна. Агрегаты WDI не входят в выборку. Пропуски исхода остаются пропусками. Лаг допустим только при наличии предыдущего календарного года.

## Проверки

- SHA-256 каждого исходного файла совпадает с манифестом.
- API не оставил непрочитанные страницы ответа.
- Ключ «страна - год» уникален.
- Расходы, ВВП, население и смертность положительны.
- Доли находятся в диапазоне 0-100.
- Сумма двух категорий смертности совпадает с общей категорией с допуском 2 на округление.
- Пропуски доступны в `reports/data_quality.json` и на графике покрытия.

Исходные ответы лежат в `data/raw`. JSON и CSV сжаты gzip. URL, время загрузки, дата обновления источника и контрольные суммы лежат в `data/raw/manifest.json`.

## Географическая основа

Карта использует [Natural Earth, admin 0 countries, 1:110 млн](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson). Для соединения служит поле `ADM0_A3`. Геометрия и названия хранятся локально в `web/data/world.json`. Антарктида не показана. URL и SHA-256 исходного GeoJSON есть в `docs/geography_source.json`. Границы нужны только для отображения и не участвуют в моделях.
